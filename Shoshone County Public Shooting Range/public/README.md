# Shoshone County Public Shooting Range

Official website for the Shoshone County Public Shooting Range — Safety First Outdoors.

## Live Website

🔗 **[https://caseyrw10.github.io/shoshone-county-shooting-range/](https://caseyrw10.github.io/shoshone-county-shooting-range/)**

## Features

- Modern responsive design built with Tailwind CSS & Google Fonts
- Dynamic range status indicator ("Range: Hot" vs "Range: Cold") based on live operational hours
- Upcoming events calendar & registration modal
- Contact inquiry form
- Safety protocols & facility overview
